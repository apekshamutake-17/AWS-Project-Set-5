# AWS Project Set 5

## Overview

This repository contains my AWS projects completed as part of my AWS Cloud Computing training.

## Projects

### Project 1 – Amazon CloudFront with S3

Created an Amazon CloudFront distribution using an Amazon S3 bucket as the origin and configured the website for HTTPS access.

**Services Used:**
- Amazon S3
- Amazon CloudFront

### Project 2 – EC2 Linux Web Server

Launched an Amazon EC2 Linux instance and configured it as a web server with the required Security Group rules.

**Services Used:**
- Amazon EC2
- Security Groups
- Linux
- Web Server

### Project 3 – DynamoDB Student Management

Created an Amazon DynamoDB table and performed basic CRUD operations for student records.

**Services Used:**
- Amazon DynamoDB

## Repository Structure

- `Project 1-CloudFront-S3` – CloudFront and S3 project
- `Project-2-EC2-WebServer` – EC2 web server project
- `Project-3-DynamoDB` – DynamoDB student management project

All three AWS projects were successfully completed with documentation and screenshots.
