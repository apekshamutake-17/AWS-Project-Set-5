# Project 1 – Amazon CloudFront with S3

## Objective
To create an Amazon CloudFront distribution using an Amazon S3 bucket as the origin and deliver S3 content through CloudFront.

## Services Used
- Amazon S3
- Amazon CloudFront

## Steps Performed

1. Created an S3 bucket.
2. Uploaded the required files to the S3 bucket.
3. Created a CloudFront distribution.
4. Selected the S3 bucket as the origin.
5. Enabled private S3 bucket access to CloudFront.
6. Used the recommended origin and cache settings.
7. Created and deployed the CloudFront distribution.
8. Tested the CloudFront distribution using the CloudFront domain name.
9. Verified the CloudFront distribution status and configuration.

## CloudFront Distribution

The CloudFront distribution was successfully created with the S3 bucket as its origin.

## Result

The CloudFront distribution was created successfully and the S3 origin was connected to CloudFront.
