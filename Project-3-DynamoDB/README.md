# Project 3 – Amazon DynamoDB Student Management

## Objective
To create an Amazon DynamoDB table and perform basic database operations for managing student information.

## Services Used
- Amazon DynamoDB

## Steps Performed

1. Opened Amazon DynamoDB in AWS Console.
2. Created a DynamoDB table for student management.
3. Configured the table with a primary key.
4. Added student records to the table.
5. Viewed the stored student records.
6. Updated student information.
7. Deleted a student record.
8. Verified the changes in the DynamoDB table.

## Database Operations

The following CRUD operations were performed:

- Create – Added student records.
- Read – Viewed student records.
- Update – Modified student information.
- Delete – Removed a student record.

## Result

The DynamoDB table was successfully created and student records were managed using basic CRUD operations.
