# Project 2 – EC2 Linux Web Server

## Objective
To launch an Amazon EC2 Linux instance and configure it as a web server.

## Services Used
- Amazon EC2
- Security Groups
- Linux
- Web Server

## Steps Performed

1. Launched an Amazon EC2 Linux instance.
2. Configured the Security Group for the EC2 instance.
3. Allowed SSH (Port 22) for secure remote access.
4. Allowed HTTP (Port 80) for web traffic.
5. Allowed HTTPS (Port 443) for secure web traffic.
6. Connected to the EC2 instance using SSH.
7. Installed and configured the web server.
8. Created a web page and tested the web server.
9. Accessed the web server using the EC2 public IP address.

## Security Group Configuration

The following ports were configured:

- Port 22 – SSH
- Port 80 – HTTP
- Port 443 – HTTPS

## Result

The EC2 Linux instance was successfully launched and configured as a web server. The web page was successfully accessed using the EC2 public IP address.
